🚀 ЗАПУСК ПРОЕКТА:
   
   1. Откройте терминал в директории проекта:
      PS C:\Users\User\Documents\Mobile\Lab1>
   
   2. Выполните команду:
      npx expo start
   
   3. Выберите способ запуска:
      • Нажмите 'w' для запуска в браузере
      • Или отсканируйте QR-код через приложение Expo Go на телефоне
   
   4. Переключитесь на таб "Profile" (иконка 👤)

🔧 ЧТО МОЖНО ИЗМЕНИТЬ:
   
   1. Имя пользователя:
      Откройте profile.tsx, найдите:
      <ThemedText type="title" style={styles.name}>
        Алексей
      </ThemedText>
      Замените "Алексей" на нужное имя.
   
   2. Описание:
      В том же файле найдите:
      <ThemedText style={styles.description}>
        Молодой программист...
      </ThemedText>
      Измените текст описания.
   
   3. Аватар:
      Замените изображение в:
      source={require('@/assets/images/partial-react-logo.png')}
      Или поместите новое изображение в папку assets/images/

   4. Цвет кнопки:
      В стилях найдите:
      backgroundColor: '#007AFF'
      Замените на нужный цвет (например, '#34C759' для зеленого)
