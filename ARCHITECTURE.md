## Принципы проектирования

### KISS (Keep It Simple, Stupid)
- Минимум зависимостей
- Простая структура компонента
- Понятный код без излишеств

### DRY (Don't Repeat Yourself)
- Переиспользование ThemedView и ThemedText
- Централизованные стили (StyleSheet.create)
- Единый подход к оформлению

### SOLID

**S - Single Responsibility**
- ProfileScreen отвечает только за отображение профиля
- Стили вынесены в отдельный объект
- Обработка событий вынесена в отдельную функцию

**O - Open/Closed**
- Легко расширить (добавить поля, изменить стили)
- Не нужно модифицировать существующий код для расширения

**L - Liskov Substitution**
- Использует стандартные компоненты React Native
- Можно заменить на кастомные без изменения интерфейса

**I - Interface Segregation**
- Четкие пропсы для каждого компонента
- Минимальный интерфейс для каждого элемента

**D - Dependency Inversion**
- Зависит от абстракций (ThemedView, ThemedText)
- Не зависит от конкретных реализаций

### YAGNI (You Aren't Gonna Need It)
- Нет лишних функций
- Только необходимый функционал
- Простая обработка нажатия кнопки (alert)

## Стилизация (Flexbox)

```css
container: {
  ┌────────────────────────────────────────┐
  │  display: flex (по умолчанию)          │
  │  flex-direction: column (по умолчанию) │
  │                                        │
  │  ┌────────────────────────────────┐   │
  │  │  alignItems: 'center'          │   │ ← Горизонтальное центрирование
  │  │  justifyContent: 'center'      │   │ ← Вертикальное центрирование
  │  └────────────────────────────────┘   │
  │                                        │
  │  gap: 20  ← Расстояние между дочерними │
  │            элементами                  │
  └────────────────────────────────────────┘
}
```

## Данные (State)

Текущая реализация:
- ✅ Статические данные (имя, описание)
- ❌ Нет состояния (useState)
- ❌ Нет сохранения данных

Рекомендуемое расширение:
```tsx
const [name, setName] = useState('Алексей');
const [description, setDescription] = useState('...');
const [avatar, setAvatar] = useState(require('@/assets/images/...'));
```

## Обработка событий

```tsx
handleEditPress()

  alert('Редактировать профиль')
    ↓
  (расширение) → Открыть экран редактирования
```
