# Лабораторная работа №2: Навигация в React Native с Expo Router

## Цель работы
Реализация навигации между экранами мобильного приложения с использованием Expo Router, передача параметров между экранами, создание динамических маршрутов.

## Структура проекта

```
Lab1/
├── app/
│   ├── index.tsx              # Главная страница
│   ├── catalog/
│   │   └── index.tsx          # Список товаров
│   └── details/
│       └── [id].tsx           # Детали товара (динамический маршрут)
├── components/
│   └── ProductCard.tsx        # Переиспользуемый компонент карточки товара
├── data/
│   └── products.ts            # Mock-данные товаров
└── README_LAB2.md             # Документация
```

## Архитектура

### Маршрутизация (Expo Router)
- **File-based routing**: маршруты определяются структурой папок в `app/`
- **Динамические маршруты**: файл `[id].tsx` создаёт маршрут с параметром
- **Навигация**: `router.push()` для перехода, `useLocalSearchParams()` для чтения параметров

### Компоненты

#### ProductCard
- Универсальный компонент для отображения товара
- Принимает `product` и опциональный `onPress`
- Автоматическая навигация на детали при клике

#### Экраны

1. **HomeScreen** (`app/index.tsx`)
   - Кнопка перехода к каталогу
   - Промо-блок с рекомендованным товаром
   - Список популярных товаров

2. **CatalogScreen** (`app/catalog/index.tsx`)
   - FlatList для эффективного рендеринга списка
   - Каждая карточка ведёт на экран деталей

3. **ProductDetailScreen** (`app/details/[id].tsx`)
   - Динамический маршрут: `/details/1`, `/details/2`, etc.
   - Чтение параметра `id` через `useLocalSearchParams`
   - Поиск товара по ID из mock-данных
   - Обработка случая "товар не найден"

### Данные

#### products.ts
```typescript
interface Product {
  id: string
  name: string
  description: string
  price: number
  image: string
}
```
- Массив mock-данных для демонстрации
- Функция `getProductById()` для поиска

## Передача параметров

### Отправка
```typescript
router.push(`/details/${product.id}`)
```

### Получение
```typescript
const { id } = useLocalSearchParams<{ id: string }>()
```

## Принципы разработки

- **KISS**: минимальная сложность, только необходимые функции
- **DRY**: компонент `ProductCard` переиспользуется на всех экранах
- **Clean Code**: понятные имена, разделение ответственности
- **TypeScript**: типизация пропсов и параметров маршрутов

## Тестирование навигации

1. Запустите приложение
2. На главном экране нажмите "Перейти к каталогу" → переход на `/catalog`
3. Нажмите на любой товар в списке → переход на `/details/{id}`
4. На экране деталей нажмите "Назад" → возврат к списку
5. На главном экране кликните по промо-товару → переход на `/details/1`

## Ошибки и обработка

- Если передан несуществующий ID, показывается сообщение "Товар не найден"
- Кнопка "Назад" возвращает пользователя к предыдущему экрану
- Все изображения загружаются с placeholder-сервиса для демонстрации

## Расширение функционала

Для добавления новых экранов:
1. Создайте файл в соответствующей папке `app/`
2. Используйте `router.push('/new-screen')` для навигации
3. Для параметров: `router.push('/screen?param=value')` или динамические маршруты `[param].tsx`
