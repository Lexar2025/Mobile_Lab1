# Экран профиля пользователя - Техническая документация

## Задача
Создать экран профиля пользователя с:
- Именем пользователя
- Фотографией (аватар)
- Кратким описанием
- Кнопкой "Редактировать профиль"
- Стилизацией с использованием Flexbox

## Реализация

### 1. Структура файлов

```
app/(tabs)/
├── index.tsx          # Главный экран
├── explore.tsx        # Экран обзора
├── profile.tsx        # ← НОВЫЙ: Экран профиля
└── _layout.tsx        # Навигация (обновлено)
```

### 2. Созданные файлы

#### `app/(tabs)/profile.tsx`

**Компоненты экрана:**
- `Image` - аватар пользователя с закруглением
- `ThemedText` - имя и описание
- `TouchableOpacity` - кнопка редактирования
- `ThemedView` - контейнер с темной/светлой темой

**Стили (StyleSheet.create):**

| Элемент | Свойства | Примечание |
|---------|----------|------------|
| `container` | `flex: 1`, `alignItems: 'center'`, `justifyContent: 'center'` | Flexbox: центрирование по вертикали и горизонтали |
| `avatar` | `borderRadius: 60`, `shadowColor`, `elevation` | Закругленное изображение + тень |
| `name` | `fontSize: 28`, `fontWeight: 'bold'` | Заголовок имени |
| `description` | `textAlign: 'center'`, `lineHeight: 24` | Центрированный текст |
| `editButton` | `backgroundColor`, `borderRadius: 12`, `shadow` | Стилизованная кнопка |

### 3. Изменения в навигации

### 4. Архитектурные решения

#### Принцип KISS
- Использован стандартный шаблон Expo Router
- Минимум зависимостей (только из `expo-image`, `react-native`)
- Простая структура компонента

#### Принцип DRY
- Переиспользованы существующие компоненты:
  - `ThemedView` - для темной/светлой темы
  - `ThemedText` - для стилизованного текста
  - `IconSymbol` - для иконок навигации

#### Принцип SOLID
- **Single Responsibility**: Компонент отвечает только за отображение профиля
- **Open/Closed**: Легко расширить (добавить поля, изменить стили)
- **Liskov Substitution**: Использует стандартные компоненты React Native
- **Interface Segregation**: Четкие пропсы для каждого компонента
- **Dependency Inversion**: Зависит от абстракций (ThemedView, ThemedText)

### 5. Стилизация (Flexbox)

```tsx
container: {
  flex: 1,                    // Заполняет весь экран
  alignItems: 'center',       // Горизонтальное центрирование
  justifyContent: 'center',   // Вертикальное центрирование
  padding: 24,                // Отступы от краев
  gap: 20,                    // Промежуток между элементами
}
```

**Результат:** Все элементы выровнены по центру экрана.

### 6. Дополнительные стили

#### Закругления
```tsx
avatar: {
  borderRadius: 60,           // 50% от размера 120x120 = круг
}

editButton: {
  borderRadius: 12,           // Скругленные углы кнопки
}
```

#### Тени
```tsx
avatar: {
  shadowColor: '#000',        // Цвет тени
  shadowOffset: { width: 0, height: 4 },  // Смещение
  shadowOpacity: 0.3,         // Прозрачность
  shadowRadius: 6,            // Радиус размытия
  elevation: 8,               // Для Android
}

editButton: {
  shadowColor: '#007AFF',     // Синяя тень
  // ... остальные свойства
}
```
