## Как запустить

```powershell
# В директории проекта
npx expo start
```

Затем:
1. Нажмите **`w`** для запуска в браузере **ИЛИ**
2. Отсканируйте QR-код через приложение **Expo Go** на телефоне
3. Переключитесь на таб **"Profile"** (иконка 👤)

## Структура кода

```
┌─ ThemedView (container)
│  ├─ Image (avatar)
│  ├─ ThemedText (name)
│  ├─ ThemedText (description)
│  └─ TouchableOpacity (editButton)
│     └─ ThemedText (editButtonText)
```

## Стилизация (ключевые моменты)

### Центрирование (Flexbox)
```tsx
container: {
  flex: 1,
  alignItems: 'center',      // ← Горизонтально
  justifyContent: 'center',  // ← Вертикально
}
```

### Закругления
```tsx
avatar: {
  borderRadius: 60,  // ← 50% от 120 = круг
}
```

### Тени
```tsx
shadowColor: '#000',
shadowOffset: { width: 0, height: 4 },
shadowOpacity: 0.3,
shadowRadius: 6,
elevation: 8,  // ← Для Android
```

## Что можно улучшить

### Простые улучшения
1. **Изменить текст** - отредактируйте `profile.tsx`:
   ```tsx
   <ThemedText type="title" style={styles.name}>
     Ваше имя
   </ThemedText>
   ```

2. **Сменить аватар** - замените изображение:
   ```tsx
   source={require('@/assets/images/your-avatar.png')}
   ```

### Средние улучшения
3. **Редактирование** - создать экран формы
4. **Сохранение данных** - использовать `useState` или `AsyncStorage`

### Сложные улучшения
5. **Загрузка фото** - `expo-image-picker`
6. **Серверная синхронизация** - отправка данных на бэкенд

## Возникли вопросы?

1. **Экран не отображается?**
   - Проверьте, что запустили `npx expo start`
   - Переключитесь на таб "Profile"

2. **Хочу изменить цвет кнопки?**
   - В `profile.tsx` найдите `editButton`
   - Измените `backgroundColor: '#007AFF'` на нужный цвет

3. **Нужна помощь с редактированием?**
   - Скажите, какие поля нужно редактировать
   - Создам форму редактирования
