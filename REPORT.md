### Принципы проектирования

- ✅ **DRY** - переиспользование компонентов и стилей
- ✅ **SOLID** - соблюдение всех 5 принципов
- ✅ **YAGNI** - только необходимый функционал
- ✅ **Clean Code** - читаемый и понятный код

### Стилизация (ключевые моменты)

#### Flexbox
```tsx
container: {
  flex: 1,
  alignItems: 'center',      // Горизонтальное центрирование
  justifyContent: 'center',  // Вертикальное центрирование
  gap: 20,                   // Расстояние между элементами
}
```

#### Закругления
```tsx
avatar: {
  borderRadius: 60,  // 50% от 120 = круг
}
editButton: {
  borderRadius: 12,  // Скругленные углы
}
```

#### Тени
```tsx
// Для аватара
shadowColor: '#000',
shadowOffset: { width: 0, height: 4 },
shadowOpacity: 0.3,
shadowRadius: 6,
elevation: 8,  // Для Android

// Для кнопки
shadowColor: '#007AFF',
// ... остальные свойства
```

## Инструкция по запуску

### Быстрый запуск
```powershell
cd C:\Users\User\Documents\Mobile\Lab1
npx expo start
```

### Способы запуска
1. **В браузере:** Нажмите `w` в терминале
2. **На телефоне:** Отсканируйте QR-код через Expo Go
3. **В эмуляторе:** Настройте Android Studio (см. документацию)

### Навигация
После запуска переключитесь на таб **"Profile"** (иконка 👤)
